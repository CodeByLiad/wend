# Wend project context

Read the shared project rules and current handoff before changing code:

@AGENTS.md
@docs/HANDOFF.md

For engine work, read `docs/engine-spec.md` completely. Read Phase 0 of
`docs/PRD.md` and skim `docs/architecture.md` for the current scope.

Keep `docs/HANDOFF.md` current before committing and pushing a session's work,
so the next Claude Code or Codex session can continue from the same facts.
Record changes, checks, relevant commits, open questions and next steps.
Shared Git notes carry the project context between machines; local agent
auto-memory, credentials, model binaries and private device reports are not
part of the repository.
